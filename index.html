01 / Working principles

Curious by

My work lives at the intersection of useful software, clear interfaces, and a healthy suspicion of unnecessary complexity.

Build from first principles

Understand the mechanism, then make the interface feel obvious. Math engines, language tools, and utilities all start there.

Keep the door open

Open source is how I learn in public, share useful work, and leave a project more understandable than I found it.

Fast, focused, privacy aware software is a feature. Good tools should help people stay in control.
